## Built around the weak spots of local models

<CardGrid>
  <Card title="Small tasks" icon="list-format">
    A planner splits the request into tasks of at most a few files each, so a 16K context window holds the task,
    its files and the answer.
  </Card>
  <Card title="Your own checks" icon="approve-check">
    Every change is proven by your project's type check, lint, build and tests. A gate that fails at baseline is
    compared, not blocking.
  </Card>
  <Card title="Evidence-gated review" icon="magnifier">
    A claim becomes a finding only when a test the harness runs fails because of it. Everything else is a
    question, clearly marked.
  </Card>
  <Card title="Every rejection explained" icon="document">
    Broken JSON, wrong edits and hallucinated APIs are thrown away and asked again, each with a reason code the
    report counts.
  </Card>
</CardGrid>

AstroJS is the first supported stack. Any OpenAI-compatible endpoint works: LM Studio, Ollama, llama.cpp's server,
vLLM, or a hosted API. The harness is Ruby with zero gems, and Apache-2.0.
